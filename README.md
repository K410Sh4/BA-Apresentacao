# Brain Artificial — Apresentação

Site institucional estático para apresentar a proposta, a arquitetura experimental e o estado de desenvolvimento do projeto Brain Artificial.

A implementação usa HTML, CSS e JavaScript nativos, sem etapa de compilação ou dependências externas.

## Publicação

O repositório está preparado para GitHub Pages a partir de `main` / `/(root)`.

1. Abra [Settings → Pages](https://github.com/K410Sh4/BA-Apresentacao/settings/pages).
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch **main** e a pasta **/(root)**, depois clique em **Save**.
4. Após o primeiro deploy, o site estará disponível em: https://k410sh4.github.io/BA-Apresentacao/
