# Estrutura do site

- `index.html`: semântica, conteúdo e componentes da página.
- `assets/css/styles.css`: identidade visual, layout responsivo, estados e animações.
- `assets/js/main.js`: navegação, acessibilidade, explorador de arquitetura, FAQ e efeitos progressivos.
- `assets/icons/ba-mark.svg`: marca vetorial original do site.
- `assets/images/`: recursos visuais gerados para a apresentação.

A implementação é estática, sem framework, sem fonte externa e sem bibliotecas JavaScript de terceiros.
